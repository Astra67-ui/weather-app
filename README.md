# 🌤️ Weather App

A simple and responsive weather application that allows users to search for a location and view its current weather information.

## 📌 About the Project

This Weather App was created as a front-end web development project to practice **HTML, CSS, and JavaScript**.

The application provides a simple interface for users to enter a location and retrieve weather information.

## ✨ Features

- 🔍 Search for a location
- 🌡️ Display current temperature
- ☁️ Display current weather conditions
- 💨 Display additional weather information
- 📱 Responsive user interface
- ⚡ Dynamic weather data using JavaScript

## 🛠️ Tech Stack

### Frontend

- **HTML5** – Provides the structure and content of the application
- **CSS3** – Handles the styling, layout, and responsive design
- **JavaScript** – Handles application logic, user interactions, and dynamic content
